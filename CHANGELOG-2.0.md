# Ledger 2.0 — Foundation refresh

## Included
- Introduced the Obsidian Black, Ice Gray, Racing Red design tokens.
- Updated the interface with a restrained premium visual system.
- Added subtle page, modal, card, navigation, and button motion.
- Added reduced-motion handling for accessibility.
- Updated Android and web theme colors to match the new identity.
- Fresh installations no longer receive a fixed set of starter habits; users begin with an empty activity list and create their own system.
- Existing IndexedDB records and the database version remain unchanged.

## Compatibility
- Existing Capacitor 6 / HTML / CSS / JavaScript architecture retained.
- No framework migration and no new runtime dependencies.
- Existing local data stores and notification plugin configuration retained.

## Important scope note
This is the first foundation/design milestone, not the completion of every item in the product vision. The next development pass should implement user-defined categories, richer activity tracking types, and the expanded onboarding/schedule experience.
